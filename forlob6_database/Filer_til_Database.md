<h1>Filer til DDU Database</h1>

I denne uge skal vi arbejde med at forstå hvordan man kan tilføje en database til vores spil samt databasesproget SQL.
Det vil gøre os i stand til at gemme spillerdata og derved sammenligne forskellige spillere. Det kan gøres ved at spilleren oplyser sit
spillernavnet (hver gang) eller at man lidt mere avanceret, laver et login til spillet. 
Vi skal arbejde med en Supabase database som er lidt mere krævende end simple databaser som f.eks. SQLite, så i skal bruge den kommende tid på at sætte databasen korrekt op.
Med Supabase får vi til gengæld en mere professionel database som kan håndtere mere data og den kan desuden gøres sikker (dog er dette ikke den primære prioritet i denne omgang).
Der er en række dokumenter og film som skal hjælpe jer med at få sat en database op og forstå hvordan den generelt virker samt lære hvordan man bruger
SQL til at lave databaseforespørgelser.
